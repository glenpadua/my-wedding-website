# Glen & Millusha's Wedding Archive

This was our wedding invite site for December 29th, 2024. Now it's a small showcase and time capsule.

Built with Next.js, React, Tailwind CSS, and Framer Motion.

## Run Locally

```bash
npm install
npm run dev
```

Live version: [fenimeetsfiltercoffee.vercel.app](https://fenimeetsfiltercoffee.vercel.app/)
